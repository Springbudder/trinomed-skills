# 文档转 Markdown

用整场对话和原件理解用户需要的文档内容。原件来自任务 `input/`，只读保留。所有交付放 `output/`，已有成果要另取文件名或版本，不覆盖。不要调用素材、PPT、IIT 或其它业务链，不安装依赖，不联网下载转换工具。

## 先做真实转换

使用 `workspace_read` 读取本技能后，调用 `workspace_script`，在 Python 中执行以下命令数组；把示例输入、输出换成任务中实际路径，不能直接照抄不存在的文件名：

```python
import subprocess
subprocess.run([
    "python3", "input/_skills/document-markdown/convert.py",
    "--input", "input/实际文件目录/原件.docx",
    "--output", "output/文档转换-v1.md",
], check=True)
```

同一脚本接受 `.pdf`、`.docx`、`.xlsx`、`.xls`、`.csv`、`.txt`、`.md`。它使用已装 Poppler、python-docx、openpyxl 或 pandas/xlrd，Excel 主读取器失败时用 LibreOffice Calc 转换临时副本，不调用模型或其它服务。检查真实退出码，再用 `workspace_read` 打开生成的 MD。需要润色标题、恢复可明确识别的结构时，模型对照实际抽取范围另写新 MD，不把不确定的内容补成事实。

## Excel、CSV 与读取范围

- XLSX 使用 openpyxl，XLS 使用 pandas/xlrd；所有工作表分别输出 Markdown 段，包括隐藏工作表。原行号与 Excel 列字母作为坐标，原首行仍然是数据，不猜哪一行是业务表头。CSV 作为一个工作表，保留前导零、空字段、`NA` 等真实文本，不自动转换为数值或公式。
- 默认每个工作表读取前 **200 行（含原首行）、50 列**；段首标明记录行列数、实际范围（例如 `A1:AX200`）和省略的行列范围。Excel 记录尺寸可能包含仅有格式的空行列。截断内容不能作为“全表已读”或“全表统计”的依据；用户要求完整读取、汇总时，应继续读取其余区间或直接用 pandas/openpyxl 处理全表，再以真实结果回答。
- 可用 `--start-row`、`--start-column` 指定从 1 开始的原行列，`--max-rows`、`--max-columns` 指定本段大小。每次输出用新文件名。例如继续读第 201–400 行、前 50 列：

```python
subprocess.run([
    "python3", "input/_skills/document-markdown/convert.py",
    "--input", "input/实际文件目录/原表.xlsx",
    "--output", "output/原表-行201至400-v1.md",
    "--start-row", "201", "--max-rows", "200", "--max-columns", "50",
], check=True)
```

- XLSX 公式保留表达式并列出保存的缓存值；无缓存时明确写“无缓存值；未计算”，不把公式当成已计算结果，已有缓存也可能过期。XLS 读取器只提供保存时的值，不能还原公式表达式或确认其缓存是否最新。
- 相交的合并区域按坐标列出，只保留锚格原值，不向其他格重复填充；锚格不在本段范围时不补填。隐藏行列按原坐标读取并明确说明。数值读取底层值，不复刻数字显示格式；图表、图片、批注与原版式不承诺还原。单元格内部换行以 `<br>` 表示。
- CSV 优先识别 BOM、UTF-8，必要时用 chardet 判断编码，严格解码，不用替换字符掩盖损坏。检测存在不确定性，核对原件；必要时增加 `--encoding gb18030` 等明确编码重新写新文件。记录号按 CSV 记录计算，引号内换行不增加记录号；分隔符按实际解析结果写明。
- LibreOffice 兜底仅在 `scratch/` 新建隔离副本，转换后再抽取；可能重新计算公式或改变格式，输出会明确标注，不能把副本缓存值说成原件保存时的值。保留原件，不覆盖已有成果；失败看真实错误后修正本次读取，不编造缺失单元格。

## PDF、扫描页与页码

- PDF 逐页用 `pdfinfo` 和 `pdftotext -layout` 抽取；真实页数来自 PDF 元数据。每页保留 `source-page` 标记及“第 N 页”，固定宽度文本块保留 Poppler 的行列空白。它不是 PDF 原版式复制，也不宣称表格已还原成结构化单元格。
- 某页没有可抽文字，可能是扫描页，也可能本来为空白。先逐页渲染查看或调用 OCR 技能，不把“无文字”直接认定为扫描件，更不能编写缺失正文。
- 扫描、混合扫描、图片中的字、错乱字形需要 OCR 技能；逐页保留原页号，并把不确定字标成 `[无法确认：…]` 或 `[无法辨认]`。两栏、跨页表、脚注阅读顺序若不确定，保留对应页的原始抽取块并说明限制。

## DOCX 表格与排版

- 普通段落与正文表格按原始 XML 顺序输出。标题样式可以转为 Markdown 标题，普通表格输出真实单元格内容；首行作为 Markdown 表头，不凭空猜列名。
- 合并单元格会展开为单元格矩阵并标注，文字可能重复；嵌套表、浮动文本框、批注、页眉页脚、复杂编号和图片不承诺还原。辅助脚本在文首写出支持说明，发现插图时提示未保留图片。
- DOCX 没有可靠的固有分页；不以字数估页，不伪造页码。用户要求分页对照时，可在任务容器用 LibreOffice 转成 PDF 后按 PDF 实际页处理。
- Markdown 可以表达的文字与表格是本技能交付范围；扫描精度和复杂版式按实际结果说明，不把纯文本抽取称为完整排版复刻。

结束时列出真实的新文件路径、转换页数（仅真实 PDF）或工作表及实际读取范围、扫描或复杂内容的处理情况。失败先检查脚本输出再修正本次转换；保留原件与已生成结果，不重放未核实的副作用。
